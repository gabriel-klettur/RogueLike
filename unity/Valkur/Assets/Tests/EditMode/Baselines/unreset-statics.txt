# [RuntimeInitializeOnLoadMethod(SubsystemRegistration)] reset hook.
#
# Domain Reload is OFF in this project, so every entry below is a field that still
# holds the last session's value when you press Play again. Most are harmless caches;
# some are latent "works on the first Play, breaks on the second" bugs.
#
# THIS FILE ONLY EVER SHRINKS.
#
#   - Adding a new unreset static fails DomainReloadStaticResetTests. Fix it by adding
#     the hook, or by marking the field [SelfHealingStatic("reason")] at the
#     declaration. Appending a line here is a deliberate, reviewable exception, not
#     the default move.
#   - Removing the last offender from a type and forgetting to delete its line here
#     ALSO fails the suite, so the list cannot rot into fiction.
#
# Format: KIND<TAB>Namespace.Type.FieldName
#   UNITYOBJ   holds a UnityEngine.Object. Highest risk: becomes a fake-null
#              MissingReference on the second Play.
#   DELEGATE   event or Action. Leaks subscribers across sessions (RUN_TWIN_SAVE class).
#   COLLECTION list/dict/array. Usually immutable lookup data; verify before trusting.
#   VALUE      plain value or reflection cache.
#
# Generated 2026-08-18 from Valkur.Core, Valkur.Data, Valkur.Infrastructure,
# Valkur.Gameplay, Valkur.UI, Valkur.UIKit.
#
