# Unity Project

Carpeta reservada para la nueva migracion del roguelike a Unity.

Siguiente paso sugerido:

1. Crear el proyecto Unity 2D (URP 2D) dentro de esta carpeta.
2. Definir estructura base (`Assets/Scenes`, `Assets/Scripts`, `Assets/Art`, `Assets/Audio`).
3. Migrar primero sistemas nucleares: movimiento, camara, tilemap, combate y guardado.
